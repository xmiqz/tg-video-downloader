# v2.2.0-beta.1 · 原生重建与响应式 Beta

> v2.2 完成 **Windows 原生壳重建**（WebView2 直连原生窗口）并全页面像素级对标 v2.1：窗口可拉伸到移动尺寸自动切换移动版式、任务编辑回归 2.1 独立窗口、任务详情回归右侧全高滑层、全局下载进度悬浮卡、液态玻璃羽化全面增强；并集中修复多轮真机实测反馈的布局、层级与可见度问题。Beta 版欢迎通过 Issues 反馈；升级前请先备份「TG视频下载器数据」目录。

## 📥 下载（按平台选择，文件名为英文，中文说明见资产标签）

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`（图形界面）｜`TGVideoDownloader_TUI_ARM64.exe`（控制台）
- **Linux**：`TGVideoDownloader_linux_x64` / `TGVideoDownloader_linux_arm64`
- **macOS**：`TGVideoDownloader_mac_x64`（Intel）/ `TGVideoDownloader_mac_arm64`（Apple Silicon），另附 `.command` 双击启动
- Windows 11 自带 WebView2 Runtime，可直接运行；首次启动输入手机号与验证码登录即可，也可点「暂不登录」以游客模式浏览本地任务。

## ✨ 新功能

- **原生壳重建**：主界面直接运行于 Windows 原生窗口（WebView2）：沉浸式深浅色标题栏、Win11 圆角与 Mica 窗口底，外观切换实时联动；应用内弹层/提示的层级体系全面重整（登录弹层 6000 层、提示 6200 层），叠加不再互相遮挡。
- **响应式布局**：窗口可拉伸至移动尺寸（360×640 起）并自动切换移动版式：表格转卡片、工具条横滑、悬浮动作条与底部导航避让、手势支持（边缘返回 / 列表滑动快捷操作 / 下拉刷新 / 聚焦保持）。
- **任务编辑独立窗口（2.1 双窗回归）**：任务详情「编辑任务」弹出专业编辑窗（任务设置 + 全条目八列密集表格：文件名 / TG 消息原文 / 时长 / 日期 / 大小 / 状态 / 操作），逐像素还原 2.1 编辑窗布局与行为（筛选 / 批量标记 / 移除 / 搬运进度弹层 / 补全回捞）；窗口可拉伸至移动尺寸并展示移动卡片版式。
- **任务详情右侧滑层（2.1 形态回归）**：桌面下任务详情从右侧全高滑出（含进度、计数、条目筛选、搜索），列表内部滚动、底部「编辑任务 / 目录 / 继续下载 / 恢复跳过 / 删除任务」按钮常驻不被推出视口；移动端保持底部弹层形态。
- **全局下载进度悬浮卡**：右下角实时显示所有下载作业（阶段、速度、条目/字节进度、取消、收起为「N 个作业」小胶囊）；移动端自动让开底部导航栏。
- **任务库账号策略（主号 / 小号 / 自动）**：任务卡上直接为「本任务后续下载使用」选择账号策略，切换即时生效；「继续」按钮回归渐变主色。
- **液态玻璃羽化增强**：登录面板、胶囊底栏、侧栏账号盒、弹层面板、提示条、下载卡等界面叠加元素统一羽化处理，液态玻璃与亮色背景下文字清晰可读。
- **浏览目录原生兜底**：选择保存目录在打包环境缺 tkinter 时自动改用 Windows 原生目录选择器，任何构建形态均可正常选目录。

## 🐛 问题修复

- 修复全页面字号、版式、间距与 v2.1 的偏差（弃用流式字号，逐值对齐 2.1）。
- 修复任务选号点击后卡在「自动」不生效（属性键错位导致选值读空被静默回退）。
- 修复任务编辑表未勾选时勾选框不可见、只能全选后操作的 2.1 遗留缺陷（现常显勾选框，命中区 44px）。
- 修复关闭弹层后约 400ms 内点击/滑动打在隐形层上无反应。
- 修复弹层点击窗外只关最上层（叠加弹层逐层关闭，不再一次全关）。
- 修复登录弹层被遮罩层盖住无法点击（层级 6000）；恢复未登录提示与启动异常提示。
- 修复登录后侧栏不显示账号与退出按钮、退出按钮被底层遮挡。
- 修复搜索已有匹配项不流式展示；修复下载条目缺失消息文字。
- 修复全局下载卡半透明透底导致文字被下层内容淹没。
- 修复样式注释内 `*/` 序列提前闭合注释、连带吞掉首条样式规则的隐患。
- 修复任务编辑窗最小尺寸不可缩至主窗大小、列表无法上下滑动、移动卡片详情不折叠。
- 修复移动版式下任务编辑页目录/筛选占满视口挤掉列表的问题（设置区并行压缩、筛选单行横滑）。
- 修复下载中视图无任务时的空排版、新建任务页多余结果筛选框等 6 项发版候选实测缺陷。

## 📋 升级与兼容性
