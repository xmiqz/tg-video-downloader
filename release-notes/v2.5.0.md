# v2.5.0 · 弦 XIAN 与下载链路舞台

> **2.x 系列第一个正式版**。v2.5 把「有因的动效」落到全局：新增角色「弦 XIAN」九态与下载链路舞台，动效统一走令牌并支持系统「减少动态效果」；同时重构新建任务命名区、保留视频引用文本，图标与品牌位由同一几何派生，登录页页脚显示版本与构建号。正式版在 beta.1 之后完成了一轮真机打磨（见「beta.1 之后的修复」）。

## 📥 下载与部署

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`｜`TGVideoDownloader_TUI_ARM64.exe`
- **Linux / macOS**：按 `linux-x64`、`linux-arm64`、`macos-x64`、`macos-arm64` 资产选择
- **NAS / Docker**：`ghcr.io/xmiqz/tg-video-downloader:v2.5.0`（amd64 / arm64）

## 🔧 beta.1 之后的修复

- **任务交互**：组头折叠（按任务记忆）+ 任务级「暂停/继续」；暂停后任务保留在「下载中」列表；忙态按钮只显示转圈。
- **舞台**：单条视频完成补飞一次「任务舱 → 本地磁盘」；折叠舞台后每任务读数并入状态带第二行；「保存位置」显示磁盘剩余空间。
- **每日壁纸**：底层保持清晰、卡面不做取景模糊（桌面/平板/手机同口径，消除左缘高光条）；可读性改由更实的磨砂底（暗 `.68/.54`、亮 `.90/.86/.78`）与加深的次级墨承担。
- **登录/抽屉**：登录与账号卡加实底；抽屉改「深色压底 + 34px 羽化模糊」；桌面登录视图显示版本号（`assets/version.json`）。
- **账号资料**：`me()` 缓存优先、冷缓存 8 秒限时；账号卡首帧读缓存，不再长时间停在「获取账号资料中…」。
- **视觉/过场**：主按钮去彩色外发光；静态亮下作业卡改中性浅投影；手机底部渐隐收到 88–120px；底栏过场取消 `.sh-viewhost` 具名，切换不再闪。

## 🎬 视觉与动效

- **弦 XIAN（九态）**：`idle / scanning / downloading / sharding / floodwait / retrying / failed / done / uploaded` 一态一形；唯一四控制点几何、圆角按比例、三层材质封顶（下翼蓝玻璃 / 上翼乳白 / 前缘亮边），无眼嘴四肢。
- **下载链路舞台**：概览页三张统计卡合并为「舞台 + 状态带」。舞台按 10 个内核阶段绘制节点、连线与飞行，状态带一行显示总体进度、完成/跳过/失败/进行/暂停、速度与剩余；队列条最多 3 条，点开就地切换主任务，不跳页。
- **阶段机一致**：前端 10 态 / 30 条阶段边与内核 `_PHASE_NEXT` 逐边契约测试比对，终态无出边、无自环。
- **六项物理**：梯形速度（端点 0、峰值 1.35×、单调）、squash & stretch、banking、anticipation、速度尾迹、节点接收反馈；跃迁只播一次。
- **动效框架**：全部时长/缓动收进令牌，视图切换用 View Transition（无引擎则淡入），分段控件滑块改用独立 thumb，概览数字滚动，卡片完成闪烁；滚动守卫只还原非读者造成的程序化滚动，不劫持用户手势。
- **降级不丢信息**：系统「减少动态效果」时全部时长归零、缓动线性、弦停止振翅，状态色与文字带保留；无 `backdrop-filter` 或小屏（≤640px）自动降模糊。本轮同时修复了显式主题下这些降级被主题块压过的问题。

## 🖥 界面与任务

- **新建任务命名区重构**：从条件区迁到搜索结果列表上方；「智能重命名（高级）」默认关，关闭时档位与命名全选禁用；档位改为互斥单选「改名 / 更宽上下文命名」，行内两态标签「已改名（已下载）/ 已登记（未下载）」，与编辑页文案逐字一致。
- **引用文本不丢**：视频正文为空但关键词命中于引用消息时，条目保留 `ref_text`（压缩空白、截 120 字），详情与编辑页显示「引用：…」，导出/导入同样携带。

## 🏷 品牌与构建信息

- **同一份几何**：favicon、应用内图标与 Windows exe ICO 全部由生产 `XIAN_GEOMETRY` 派生，不存在第二份剪影；16/24px 只留剪影，32px 起完整派生。
- **窗口图标**：GUI/TUI 构建与运行态窗口类均载入同一枚 ICO，缺失时静默降级、窗口照常创建。
- **登录页页脚**：显示版本与提交短 SHA（源码直跑显示 `dev`），并附项目地址外链；页脚贴页面底部，窄屏不越界。
