# v2.4.0-beta.2 · v2.4 发布验证门修复

> 本版是 v2.4 最终发布前的候选构建，重点修复浏览器/容器端实测发现的任务编辑、导出、主题可读性和无控制台桌面启动问题。建议升级前备份「TG视频下载器数据」目录。

## 📥 下载与部署

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`｜`TGVideoDownloader_TUI_ARM64.exe`
- **Linux / macOS**：按 CI 产出的 `linux-x64`、`linux-arm64`、`macos-x64`、`macos-arm64` 资产选择
- **NAS / Docker**：`docker pull ghcr.io/xmiqz/tg-video-downloader:v2.4.0-beta.2`，或在设置页复制生成的 `compose.yaml`

## ✨ 本版修复

- 浏览器任务编辑新增服务器目录选择器：允许根目录内浏览、上一级、子目录选择，不跟随越界符号链接。
- 浏览器编辑入口改为同页跳转，不再依赖 `window.open`，消除弹窗拦截。
- 任务导出列表和导出动作等待桥接就绪，修复空列表/初次点击误报。
- Bing 亮壁纸自适应文字、状态徽标、移除按钮与主按钮对比度；玻璃面板保留磨砂质感。
- Bing → 液态玻璃清理旧背景和亮度状态；独立编辑页同步外观与壁纸变化。
- 无控制台启动时替换无效 stdout/stderr 句柄，修复 `OSError [Errno 22] Invalid argument`。
- 桌面任务编辑页宽屏滚动修复：桌面与移动布局统一为整页滚动。
- 暗色主题下独立编辑窗标题栏、边框和文字颜色跟随主题，不再出现浅色“套壳”标签。
- 从其它设备复制数据目录后，启动时自动重定位失效的任务保存目录；目录修改不再要求 Telegram 登录。
- Docker 默认镜像 tag 更新为 `v2.4.0-beta.2`。

## ⚠️ 已知限制

- 内置 HTTP 不提供 TLS；公网部署必须置于 HTTPS 反向代理之后。
- NAS 若无法直连 GHCR，需配置镜像加速器，或先在联网机器 `docker pull` 后 `docker save/load`。
- Web 管理员会话不持久化，服务重启后需重新登录。
