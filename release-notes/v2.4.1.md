# v2.4.1 · 安全加固与大屏布局修复

> v2.4.1 是 v2.4 线的收口补丁：收紧反向代理与会话安全，修复大屏结果区右侧留白，并在 Web 页脚与 `/healthz` 暴露版本与构建号，便于确认 NAS 上运行的到底是哪个镜像。

## 📥 下载与部署

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`｜`TGVideoDownloader_TUI_ARM64.exe`
- **Linux / macOS**：按 `linux-x64`、`linux-arm64`、`macos-x64`、`macos-arm64` 资产选择
- **NAS / Docker**：`ghcr.io/xmiqz/tg-video-downloader:v2.4.1`（amd64 / arm64）

## 🔐 安全加固

- 「记住此设备」长效会话绑定设备指纹，有效期由 30 天缩短为 7 天；旧格式令牌一律失效，需重新登录一次。
- 登出改为「宽进严出」：只校验签名与过期时间，签名合法即写入吊销表。此前 UA 变化会导致登出吊销失效，现已修复；会话本身仍严格校验 UA。
- 反向代理信任收紧：仅当请求来源属于 `TGDL_TRUSTED_PROXIES` 白名单时才采信 `X-Forwarded-For` / `X-Forwarded-Proto`；回环地址 `127.0.0.1` 与 `::1` 永远可信，未配置白名单时默认只信任回环。
- 文档补充：启用可信反代后走 http 直连将拿不到 Cookie（浏览器丢弃带 `Secure` 的 `Set-Cookie`），必须走 https 访问。

## 🖥 Web 布局

- 大屏（≥1024）结果区取消 760px 固定窄带，保持单列并铺满可用宽度：名称、拟命名、摘要随行宽显示更多内容，体积与来源标签贴右缘，不再出现右侧大面积留白。
- 视图样式增加页面级版本戳，升级后浏览器不会复用旧 CSS；此前"改了看不出区别"即由旧样式缓存导致。
- `<1024` 断点与移动端版式零改动（390×844 截图逐像素一致）。

## 🏷 构建信息

- 镜像构建时注入 `TGDL_VERSION`（发布 tag）与 `TGDL_BUILD`（提交短 SHA），`/healthz` 与 `/auth/status` 均可读取。
- 首跑设置页页脚显示版本与构建号；源码直跑显示 `dev`。

## 📋 兼容性

- 数据目录与任务 JSON 完全兼容 v2.4.0；`auth.json` 保留既有字段，仅追加吊销表。
- 回滚到 v2.4.0 后，v2.4.1 签发的长效会话 Cookie 不被旧版识别，需重新登录一次（原密码有效）。
- 内置 HTTP 不提供 TLS；公网访问必须置于 HTTPS 反向代理后。
