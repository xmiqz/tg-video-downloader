# v2.7.0 发布说明

## 概览

v2.7.0 重点改进“扫新”流程与每日壁纸下的视觉表现：扫新不再改动原任务，而是预填一个独立的新任务；下载舞台在壁纸下重新呈现透明玻璃层次。任务 JSON 必需字段、数据目录与端口保持不变。

## 扫新

- 从任务卡或详情点击“扫新”，会进入预填的“新建下载”，原任务的条目、进度和标题保持不变。
- 同频道、同标题基名且保存在同一目录的任务会按整组计算水位；拆分任务之间不会因各自的进度而重复扫入。
- 扫描同时依据消息 ID 水位和日期水位，预览中已在任务的条目会灰显且默认不勾选；如果你确实要重新下载，可以手动勾选。
- 真正创建任务时还会按频道与消息 ID 做一次去重，并在完成后显示跳过数量。新任务标题带扫新日期，同时记录本次水位和扫描日期。
- 同一组任务的扫新流程不能并发提交，重复操作会被拒绝并提示。旧的“追加扫描”行为保留在任务编辑页，与“扫新”分开。

## 视觉

- 每日壁纸下，下载舞台改为透明玻璃，可以看到照片层次；内层任务卡保持略实的表面，任务名、速度、剩余时间和阶段文字仍清晰可读。
- 壁纸任务卡增加轻微模糊与更强的对比，删除、中止等操作按钮更容易辨认。
- 壁纸明暗统一按 `140/255` 的亮度阈值判断；缺少毛玻璃支持时会自动回退到实底配色。

## 稳定性

- 任务卡与详情显示容量字节统计。
- 账号状态会显示限流冷却信息。
- 修复频道实体缓存跨客户端复用的问题；实体失效后会重新获取。
- 下载中的任务不会进入追加扫描流程，避免干扰正在进行的下载。
- TUI 发现并修复了已有授权 session 时先发码的问题：现在会先 connect 并直接复用已有授权；最终 x64 TUI 已验证登录恢复、主菜单和任务菜单“追加视频”。
- 新增追加视频 / 追加扫描专项边界测试，覆盖参数校验、并发原子锁、增量水位、跨批次去重、取消 / 异常收口、线程启动失败清理和 TUI 追加水位推进。
