# v2.4.0-beta.1 · 无头 Web 服务与 NAS 部署 Beta

> v2.4 把同一套前端与下载内核同时跑在 **Windows 桌面壳** 和 **浏览器 / Docker** 两种宿主上：新增带单用户鉴权的无头 HTTP/WS 服务、ARM64 飞牛 fnOS 容器镜像、设置页内建的 NAS 一键部署面板，并补齐每日壁纸（Bing 每日一图）、任务导入导出、编辑页独立窗口等体验。Beta 版欢迎通过 Issues 反馈；升级前请先备份「TG视频下载器数据」目录。

## 📥 下载（按平台选择，文件名为英文，中文说明见资产标签）

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`（图形界面）｜`TGVideoDownloader_TUI_ARM64.exe`（控制台）
- **Linux**：`TGVideoDownloader_linux_x64` / `TGVideoDownloader_linux_arm64`
- **macOS**：`TGVideoDownloader_mac_x64`（Intel）/ `TGVideoDownloader_mac_arm64`（Apple Silicon），另附 `.command` 双击启动
- **NAS / Docker**：`docker pull ghcr.io/xmiqz/tg-video-downloader:v2.4.0-beta.1`，或使用设置页内建面板生成的 `compose.yaml`
- Windows 11 自带 WebView2 Runtime，可直接运行；首次启动输入手机号与验证码登录即可，也可点「暂不登录」以游客模式浏览本地任务。

## ✨ 新功能

- **无头 Web 服务**：`python -m server_app` 前台入口，桌面壳与 Linux/Docker 复用同一套 HTTP/WebSocket 应用；`/healthz` 适配容器健康检查，`SIGTERM` 优雅退出。
- **单用户鉴权**：远程首次启动生成 `/data/.setup-token`，设置管理员密码后立即删除；PBKDF2-HMAC-SHA256 加盐存储，会话 Cookie 为 HttpOnly + SameSite=Strict；RPC 与 WebSocket 统一鉴权，错误密码按来源限速。
- **浏览器首跑向导**：管理员密码、API 凭证、手机号、验证码、2FA 全流程响应式；明确区分 Web 管理员密码与 Telegram 两步验证密码。
- **NAS 一键部署**：设置页「NAS 一键部署（Docker）」卡片按端口 / 镜像 / 数据目录实时生成 `compose.yaml` 与启动命令，一键复制到群晖、飞牛 fnOS、Unraid 即可运行。
- **每日壁纸主题**：Bing 每日一图，后端缓存并同源下发，每天 00:00 自动更新；可保存历史壁纸、逐张删除、上传自定义背景，断网仍显示已缓存图片。
- **任务导入 / 导出**：导出包只含条目元数据（名称/大小/日期/状态），不含任何视频文件；导入时按本机下载根目录重新落位，条目一律回到待下载状态。
- **浏览器内播放**：无头模式下「打开文件」改为同源直链，交给浏览器流式播放/保存，支持 Range 拖动。
- **编辑页独立窗口**：桌面壳弹出原生辅助窗，浏览器模式打开独立标签页，不再退回布局崩坏的壳内路由。
- **液态玻璃按宿主裁剪**：只有拥有原生窗口的 Windows 桌面壳才显示该选项，浏览器/容器不再出现无法实现的入口。

## 🐛 问题修复

- 修复非 ASCII 凭据触发 `compare_digest` TypeError，导致 500 / WebSocket 崩溃而非干净的 401。
- 修复 `.gitignore` 吞掉 `requirements-*.txt`，CI 与 Docker 构建从未真正跑通。
- 修复容器在 `--cap-drop ALL` 下入口脚本以 rc1 退出。
- 修复 4 处原型链查表（bridge 白名单 / active.js），避免 `toString` 之类属性被当作合法事件或方法。
- 修复启动不恢复 Telegram 会话，导致搜索永久转圈。
- 修复 logger 无 handler、错误静默丢失。
- 修复无头模式编辑页 fallback 到崩坏的壳内路由。
- 修复设置页导出列表始终为空（`.tp-items` 未挂到 `.tp-list`）。
- 修复未登录时导出与壁纸功能不可用（不再依赖 `loginMode`）。
- 修复桌面端每日壁纸报 `FileNotFoundError`：冻结态 SSL 证书路径缺失，现随包 `certifi` 并由运行时注入证书。
- 修复桌面端壁纸只有标题不显示图片：`<img>` / CSS `url()` 无法携带 Bearer，资源路由现支持 `?t=` 令牌。
- 修复编辑任务一次点击弹出两个窗口，以及 `window.open(..., "noopener")` 按规范恒返回 null 导致误报「被浏览器拦截」。
- 修复「浏览」按钮报「缺少 folderpicker.cs」：该 COM shim 现随包发布。
- 修复编辑窗未跟随每日壁纸主题、玻璃材质与主壳不一致。
- 修复底部出现 WebView2 网址悬浮条，看起来像套壳浏览器。
- 优化弹层展开/收起的过渡动画，位移与遮罩改走合成层，动画跟随显示设备刷新率。
- 修复 NAS 卡片复制按钮在 WebView2 中静默无效果，现优先 `execCommand` 并给出可见反馈。

## 🔒 安全与稳定性

- 根文件系统只读，仅 `/data` 持久可写；容器以非 root 运行、`cap_drop: ALL`、`no-new-privileges`。
- 无头模式禁止在服务器上调用文件管理器/文件夹选择器，目录写操作限制在允许根目录。
- 任务保存防抖合卷 + 终态强制落盘 + 三份备份轮转。

## ⚠️ 已知限制

- 内置 HTTP 不提供 TLS，公网或不可信网络必须置于 HTTPS 反向代理之后。
- 浏览器版不能在用户电脑上打开服务器侧文件或目录（改用同源直链在浏览器内播放）。
- Web 管理员会话不持久化，重启服务后需重新登录。
- NAS 若无法直连 GHCR，需自行配置镜像加速器，或在本机 `docker pull` 后 `docker save` / `load`。
