## TG 视频下载器 v2.4.0-beta.1

### 无头 Web 服务

- 新增 `python -m server_app` 前台入口，Windows 桌面壳与 Linux 浏览器版复用同一套 HTTP/WebSocket 应用。
- 支持数据目录、监听地址、端口、允许目录和反向代理相关环境变量/配置文件。
- 新增 `/healthz`，适配 Docker 健康检查。
- 支持 `SIGTERM` 优雅退出，容器停止时正常关闭服务与下载引擎。

### 单用户鉴权

- 远程访问首次启动生成 `/data/.setup-token`，设置管理员密码后立即删除。
- 密码使用 PBKDF2-HMAC-SHA256 加盐保存，会话 Cookie 为 HttpOnly + SameSite=Strict。
- RPC 与 WebSocket 统一鉴权；错误密码按来源限速。
- Windows 桌面一次性 Bearer 路径保持兼容。

### 浏览器首跑

- 新增响应式首跑向导：管理员密码、API 凭证、手机号、验证码、2FA。
- 明确区分 Web 管理员密码与 Telegram 两步验证密码。
- 无头模式禁止在服务器上调用文件管理器/文件夹选择器，目录写操作限制在允许根目录。

### Docker 与 CI

- 新增多阶段 Dockerfile、Compose 模板和非 root 入口。
- 根文件系统只读，仅 `/data` 持久可写，日志使用 stdout。
- 新增 linux/amd64 + linux/arm64 buildx 构建与 GHCR 发布流水线。
- 新增配置、鉴权、RPC/WebSocket 和目录边界自动测试。

### 已知限制

- 浏览器版不能在用户电脑上打开服务器侧文件或目录；任务编辑改用浏览器路由。
- 内置 HTTP 不提供 TLS，公网/不可信网络必须使用 HTTPS 反向代理。
- 真实 Telegram 登录与跨架构真机下载仍需在发布前走查。
