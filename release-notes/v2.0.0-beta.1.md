# v2.0.0-beta.1 · 首个公开 Beta

> v2.0 为**原生壳重构版本**，业务功能与 v1.2.6 对齐（平替），不引入功能变更。Beta 版欢迎通过 Issues 反馈；升级前请先备份「TG视频下载器数据」目录。

## 📥 下载（按平台选择，文件名为英文，中文说明见资产标签）

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`（图形界面）｜`TGVideoDownloader_TUI_ARM64.exe`（控制台）
- **Linux**：`TGVideoDownloader_linux_x64` / `TGVideoDownloader_linux_arm64`
- **macOS**：`TGVideoDownloader_mac_x64`（Intel）/ `TGVideoDownloader_mac_arm64`（Apple Silicon），另附 `.command` 双击启动
- Windows 11 自带 WebView2 Runtime，可直接运行；首次启动输入手机号与验证码登录即可。

## 🚀 重大更新

- **全新原生桌面壳**：Windows GUI 改用原生 Win32 窗口 + WebView2（纯 ctypes COM 绑定），移除 pywebview / pythonnet / .NET 依赖链，启动更快、占用更低。
- **本地通信架构重建**：宿主内置进程内 HTTP/WebSocket 服务（FastAPI + uvicorn），界面操作即时响应、下载进度实时推送。
- **x64 / ARM64 双架构原生单文件**：Windows on ARM 运行原生 ARM64 程序，不再依赖 x64 模拟；x64 程序在 ARM64 机器模拟运行同样验证通过。
- **安装包瘦身**：ARM64 GUI 约 19.8 MB、x64 GUI 约 24.5 MB。

## ✨ 界面与视觉

- 三种外观：**静态暗**（默认）、**静态亮**、**液态玻璃**（实时采样窗口后方画面并霜化）。
- 优化液态玻璃观感：高斯霜化、色彩还原与亮边高光。
- 窄窗口自适应：高级筛选自动换行、匹配模式按钮等分、体积区间输入框等宽完整显示。

## 🔒 安全

- 本地服务仅监听 `127.0.0.1` 随机端口，每次启动随机 Bearer 令牌；WebSocket 首帧强制鉴权。

## 🐛 问题修复

- 修复 x64（含 ARM64 机器上的 x64 模拟）可能加载错误架构 WebView2Loader 致界面无法加载。
- 修复源码直启时模块重复加载致屏幕放大镜回调未注册。
- 修复窄宽度下高级筛选行溢出、正则选项被遮挡、体积输入框裁切。

## 📋 升级与兼容性

- 可直接使用 v1.2.6 数据目录，任务 JSON 格式零改动；**建议升级前完整备份数据目录**。
- 业务功能与 v1.2.6 一致：五种匹配模式、评论区搜索、1–8 路并发、分片断点续传、moov 快启、大任务自动拆分、内容去重。

## ⚠️ 已知限制（计划在 v2.1 改进）

- 引用消息 / 转发来源 / 相册组首条携带文案的视频，关键词可能搜不到。
- 超大频道搜索需等待全量扫描，暂无分批展示与搜索进度。
- 老任务「继续」的对账、引用刷新、搬运等阶段暂无界面进度。
- 移动下载目录暂无进度条；仅支持单账号，暂无小号调度；暂无「暂不登录」离线模式。
- Linux / macOS 仅命令行版。
