# v2.5.1 · 更统一、更清晰的玻璃界面

> 保留 v2.5 的 TVG 风格与移动底栏，把桌面、浏览器和移动端的玻璃材质收敛为一套统一层级，并提升每日壁纸下的可读性。

## 主要变化

- 移动底栏作为 `nav` 母版，桌面侧栏、抽屉统一材质；账号脚注不再叠第二块白色玻璃。
- 内容卡、设置卡、任务库、编辑器、舞台外壳统一为 `panel`，并按壁纸采样亮度切换暗/亮透明材质。
- 桌面内容面板不再从侧栏采样，侧栏按钮悬停不会把亮条带进卡片左缘。
- 中性按钮、分段选择框、文本输入复用 `nav` 玻璃，提供 `xs / sm / md / lg` 四级高度。
- 内容面板保持亮度感知的半透明玻璃、1px 轻边与单层顶部高光；彩虹只保留在移动底栏。
- 分段选择框选中 thumb 改为中性液态玻璃环（轻 tint、1px 镜面渐变边、3px 局部模糊），不使用白底或彩虹。
- 分段选择框首屏等待真实布局尺寸后再显示 thumb，不再出现左侧细竖条。
- 独立任务编辑页补齐共享 tokens，筛选分段、按钮、输入框与批量条统一到 control/overlay 材质。
- 移动底栏新增独立滑动指示器，页签切换按 `transform/width` 弹簧位移；FAB 与登录不参与。
- 底栏指示器取消 width 插值并增加零尺寸保护，避免切换时胶囊被拉长跨过中央 FAB。
- 视频块、任务行、队列块和嵌套块统一为 `inset`，不再出现玻璃套玻璃。
- 登录、确认、详情、Toast、动作条统一为 `overlay`，用更高不透明度和层级阴影区分当前焦点。
- 液态玻璃只作为性能降级，不再是另一套视觉。
- 壁纸主题增加阅读底并移除玻璃面板内文字光晕，缓解文字发糊。
- 每日壁纸下舞台外壳提升到 `panel` 材质，并增加克制的暗色阅读底，保证任务名、进度和状态可读。
- 首次设置页改用同源 `xian-icon.svg`，与侧栏、登录徽章、favicon 和 Windows 图标保持一致。
- 登录与账号弹层底部显示版本号与构建号，版本信息随卡片显示，不再贴在视口底边。
- UI 字体统一为 `--font-ui`，避免不同布局切换字体栈。

## 兼容性

- RPC 方法集仍为 56 项，无新增接口。
- 任务 JSON、数据目录、导出包、NAS/Docker 路径不变。
- 无新增第三方运行时依赖。
