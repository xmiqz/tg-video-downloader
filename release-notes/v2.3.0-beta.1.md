# v2.3.0-beta.1 · 智能重命名与稳定性 Beta

> v2.3 引入**智能重命名**：按搜索关键词的前后文自动生成语义化文件名，搜索结果行内展示拟命名可编辑，任务创建后下载完成即自动命名；「编辑任务」内提供命名工作台（命名前后预览 / 可编辑 / 是否重命名勾选 / 一键全选 / 多选还原原始名）。同时强化下载内核（错误分类自动重试、断网感知、启动对账、慢任务让路、账号健康巡检、保存防抖与备份轮转）与搜索体验（深度扫描突破 5000 条上限、结果即时显示、高级详情）。Beta 版欢迎通过 Issues 反馈；升级前请先备份「TG视频下载器数据」目录。

## 📥 下载（按平台选择，文件名为英文，中文说明见资产标签）

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`（图形界面）｜`TGVideoDownloader_TUI_ARM64.exe`（控制台）
- **Linux**：`TGVideoDownloader_linux_x64` / `TGVideoDownloader_linux_arm64`
- **macOS**：`TGVideoDownloader_mac_x64`（Intel）/ `TGVideoDownloader_mac_arm64`（Apple Silicon），另附 `.command` 双击启动
- Windows 11 自带 WebView2 Runtime，可直接运行；首次启动输入手机号与验证码登录即可，也可点「暂不登录」以游客模式浏览本地任务。

## ✨ 新功能

- **智能重命名**：按关键词命中句（自动断句、含前后文）生成语义化文件名，自动清洗非法字符、重名自动「 (N)」后缀、扩展名保真、长度合法；新建下载搜索结果行内展示拟命名并可随时编辑，任务创建后下载完成即按此命名。
- **命名工作台（编辑任务 · 高级）**：命名前后预览 + 可编辑 +「是否重命名」勾选（取消勾选即使用并展示原文件名）+ 一键「命名全选 / 全不选」+「应用命名」（已下载文件立即改名，未下载条目登记、下载完成即命名）+「还原命名」（勾选多选，一键还原原始文件名）。
- **上下文宽窄两档**：命名上下文可选标准（约 30 字）或更宽（约 100 字），新建搜索与编辑窗各一个开关；档位随任务记录，编辑窗可随时切换重算命名建议。
- **深度扫描（突破 5000 条）**：高级筛选新增开关，开启后可覆盖更早的历史消息（安全上限 10 万条）；配套场景化提示文案（已走服务端搜索 / 纯外部文本命中 / 深度扫描触顶三种情形分流给出后续操作建议）。
- **搜索体验**：命中条目随扫描持续流式即时显示（不再整轮空转）；结果行可展开「高级详情」（完整文件名 / 日期大小来源 / 消息正文 / 引用文本全文）。
- **下载内核增强**：下载错误三分类自动重试（3/6/12 次封顶，FloodWait 不计次，file_reference 自动刷新）+ 任务级「重试次数（0-8）」设置；断网感知（等待期暂停计时、分片停滞自动升级重试）；启动对账（按磁盘事实重建任务状态）；慢任务自动让路（持续低速条目自动暂停、冷却后恢复排队尾）；账号健康巡检（异常自动退避 / 恢复 / 回池）。
- **数据可靠性**：任务保存防抖合卷 + 终态强制落盘 + 三份备份轮转，写盘异常不中断下载。

## 🐛 问题修复

- 修复搜索零散命中时结果列表长时间空白、须等全部扫描完成才显示的问题。
- 修复任务详情滑层在条目多时标题与底部按钮排被裁、整体无法滚动的问题（面板定高、列表内滚、按钮常驻）。
- 修复移动版式下编辑窗上半部无法滚动、条目列表不可达的问题（窄屏整页单滚，上半部随手滑走）。
- 修复 TUI 深度扫描提示在管道 / 脚本驱动下吞掉后续应答导致挂死的问题。
- 修复外部文本补抓预算与配额口径问题；深度扫描触顶提示不再误导。
- 命名面板移动端紧凑化：行区加高（同屏约 6-8 条）、两行排版、说明收进悬浮提示。
- 应用命名结果提示明确区分「已改名（文件已重命名）」与「已登记（未下载条目下载完成即命名）」。

## 📋 升级与兼容性

- 可直接使用 v1.2.6 / v2.0 / v2.1 / v2.2 的「TG视频下载器数据」目录，任务 JSON 向后兼容（智能重命名仅新增可选字段：条目 `rename` / `orig_name`，参数 `query` / `name_wide` / `retries`，既有键零改动）；**建议升级前完整备份数据目录**。
- 内部本地协议方法集固定为 45 个（名称集合与 v2.2 零增删），本地数据与配置零迁移。
- 无新增第三方运行时依赖，Windows 仍需 WebView2 Runtime。

## ⚠️ 已知限制

- Linux / macOS 仍仅提供命令行版（图形版与 NAS 版计划随跨端版本提供）。
- 未下载条目的拟命名在下载完成时才落到文件名；旧任务未记录搜索关键词的，命名建议按正文头部上下文生成。
