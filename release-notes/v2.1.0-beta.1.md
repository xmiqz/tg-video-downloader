# v2.1.0-beta.1 · 功能增强 Beta

> v2.1 围绕「**所有功能在界面立即响应**」重做交互链路：统一后台作业与实时进度，修复引用/相册/转发搜索盲区，新增大频道流式搜索、下载全阶段进度、移动目录进度、多账号（小号）与限速分流、游客离线模式；并修复多轮真机复测发现的登录可靠性问题。Beta 版欢迎通过 Issues 反馈；升级前请先备份「TG视频下载器数据」目录。

## 📥 下载（按平台选择，文件名为英文，中文说明见资产标签）

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`（图形界面）｜`TGVideoDownloader_TUI_ARM64.exe`（控制台）
- **Linux**：`TGVideoDownloader_linux_x64` / `TGVideoDownloader_linux_arm64`
- **macOS**：`TGVideoDownloader_mac_x64`（Intel）/ `TGVideoDownloader_mac_arm64`（Apple Silicon），另附 `.command` 双击启动
- Windows 11 自带 WebView2 Runtime，可直接运行；首次启动输入手机号与验证码登录即可，也可点「暂不登录」以游客模式浏览本地任务。

## ✨ 新功能

- **暂不登录（游客模式）**：无需登录即可离线浏览任务库、管理本地条目、打开下载文件、修改外观与下载目录；需要联网的操作会弹出登录卡，登录成功后自动继续刚才被打断的操作。
- **引用 / 相册 / 转发文案搜索修复**：关键词在被引用消息、同组相册（含组首条）或转发来源里时，现在也能搜到对应视频；结果标注命中来源与命中文本片段。
- **大频道流式搜索**：首批结果约 2 秒即出并持续增量追加，界面实时显示扫描阶段、已扫描数 / 已匹配数 / 最早日期；可随时取消，断网重连后进度自动恢复。
- **下载全阶段进度可见**：新建下载、老任务「继续 / 仅重试失败」后立即可见 准备 → 取消息 → 刷新引用 → 下载（分片）→ 限速等待 → 对账 → 完成 各阶段，错误直接显示在界面上。
- **移动保存目录带进度**：搬运已下载文件时显示当前文件名、第 i/n 个、字节与总百分比；中途失败不留半截指向，可安全重试。
- **处处即时响应**：所有耗时操作统一为后台作业，点击即有反馈、进行中防重复点击；程序重启后在途任务状态也能恢复显示。
- **多账号（小号）**：支持添加 / 移除多个小号（手机号 → 验证码 → 两步密码），条目可指定「主号 / 小号 / 自动」，账号可打彩色标签；TUI 同步提供账号管理菜单。
- **登录流程更可靠**：
  - 启动不再用旧手机号自动发码，停在手机号步、旧号码仅帮你预填；
  - 验证码实际已送达但接口报可恢复错误时，可点「已收到验证码？直接输入」直接进码步；被限速时提示明确等待秒数；
  - 获取账号资料失败可在侧栏直接重试，主号"待连接"可在账号行直接重连，不必重启；
  - 小号添加失败可同口径恢复；验证码 / 两步密码步新增「返回」按钮，自由往返不清空输入；取消添加后可立即重新添加。

## 🐛 问题修复

- 修复全新目录首次启动报内置凭证 KeyError（现自动补全，无需手工配置）。
- 修复 TUI 账号菜单在无账号时渲染报错。
- 修复小号添加后永久显示"连接中"（静默预热 + 自动补刷 + 超时显"待连接"）。
- 修复启动时登录卡闪盖主界面（先显示任务主壳，再按连接结果分流）。
- 修复有小号时的退出语义：首退注销主号并把小号原子提升为主号，再退才关闭。
- 修复下载中列表的标签、浮层避让、取消态与重启后残留忙碌态等交互问题。

## 📋 升级与兼容性

- 可直接使用 v1.2.6 / v2.0 的「TG视频下载器数据」目录，任务 JSON 格式零改动；**建议升级前完整备份数据目录**。
- 无新增第三方运行时依赖；Windows 需 WebView2 Runtime（Win11 预装，Win10 多数已自带）。

- 窄屏 / 平板响应式布局计划在 v2.2。
