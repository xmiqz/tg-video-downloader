# v2.4.0 · 跨端下载器正式版

> v2.4 完成 Windows 桌面、浏览器 Web、NAS Docker 三端统一。本版在 beta.2 基础上补齐 Linux CI 平台分层，并在飞牛 fnOS ARM64 真机完成部署、登录、重启持久化与健康检查。

## 📥 下载与部署

- **Windows x64**：`TGVideoDownloader.exe`（图形界面）｜`TGVideoDownloader_TUI.exe`（控制台）
- **Windows ARM64（WOA）**：`TGVideoDownloader_ARM64.exe`｜`TGVideoDownloader_TUI_ARM64.exe`
- **Linux / macOS**：按 `linux-x64`、`linux-arm64`、`macos-x64`、`macos-arm64` 资产选择
- **NAS / Docker**：`ghcr.io/xmiqz/tg-video-downloader:v2.4.0`

## ✨ 本版能力

- Windows 原生 WebView2 桌面壳，支持 x64 / ARM64。
- 浏览器 Web 管理端：单用户管理员密码、首跑向导、HTTP/WebSocket 实时任务。
- Docker 只读根文件系统、非 root、`cap_drop: ALL`、amd64/arm64 多架构镜像。
- 任务编辑、任务导入导出、Bing 每日壁纸、历史壁纸与背景上传。
- 智能重命名、多账号、断点续传、分片下载、搜索筛选与全阶段进度。

## 🔧 本版关键修复

- 桌面任务编辑页宽屏滚动统一为整页滚动。
- 独立编辑窗标题栏、边框和文字颜色跟随主题。
- 复制数据目录到新设备后，失效任务绝对路径自动重定位。
- 任务目录修改不再要求 Telegram 登录，未登录也可整理本地任务。
- 浏览器目录选择、同页编辑、任务导出竞态、Bing 亮壁纸可读性修复。
- Linux CI 不再收集 Windows-only WebView2 测试。

## ⚠️ 已知限制

- 内置 HTTP 不提供 TLS；公网访问必须置于 HTTPS 反向代理后。
- Web 管理员会话不持久化，服务重启后需重新登录。
- 若 NAS 无法直连 GHCR，可先 `docker pull` 后 `docker save/load` 导入同一镜像。
