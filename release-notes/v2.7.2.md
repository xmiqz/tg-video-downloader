# v2.7.2 发布说明

## 概览

v2.7.2 是下载舞台状态校正补丁版本：账号池“空闲”改为从任务快照实时统计，下载中舞台的任务舱、状态带和任务组头补充“已下载 / 总大小”，窄屏状态带隐藏体积项以避免挤压。任务 JSON 必需字段、数据目录与端口保持不变。

## 稳定性与修复

- 修复下载中舞台账号池“空闲”与任务实际下载状态不一致：账号 `busy` 改为从任务快照实时统计。

## 界面

- 下载中舞台任务舱、状态带、任务组头补充“已下载 / 总大小”。
- 窄屏状态带隐藏体积项以避免挤压，舞台画布仍显示大小。

## 升级说明

- 固定版本镜像：`ghcr.io/xmiqz/tg-video-downloader:v2.7.2`。
- 从 v2.7.1 升级时拉取新镜像并重新创建容器，例如执行 `docker compose pull && docker compose up -d`；如用 `.env` 覆盖了 `TGVD_IMAGE`，需先将镜像 tag 改为 `v2.7.2`。
- 数据目录、导出包格式、容器卷名与端口不变，Web 端口仍为 `8787`；无需迁移或删除用户数据卷。
- 升级前照常备份 `/data`；命名卷与 bind mount 的具体命令见 [备份 / 升级 / 回滚手册](../docs/nas-backup-restore.md)。

## 兼容性

- 任务 JSON 必需字段、数据目录、导出包格式、容器卷名与 `10001:10001` 运行用户不变。
- `compose.yaml` 默认镜像指向 `v2.7.2`，继续支持 `TGVD_DATA_DIR` 绑定宿主机目录；宿主机 bind mount 仍需预先设置为 `10001:10001`。
- 未引入需要迁移或删除用户数据卷的升级步骤。
