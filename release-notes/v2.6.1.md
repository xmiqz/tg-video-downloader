# v2.6.1 发布说明

> 基于 v2.6.0 的补丁版本：修复下载中改名被旧会话快照写回，并修复 Tag 触发的 GHCR 发布流水线。

## 修复

- 下载中修改任务标题或条目名后，live 会话的旧快照会在下一次强制保存时把改名写回旧值；现在改名/恢复会同步到会话快照。
- 已下载条目的原文件不存在时，改名直接提示“原文件不存在，无法改名”，不再记录一个永远无法应用的拟用名。
- 容器发布流水线读取 preflight 输出时误用了不存在的 `tag` 键，导致正式 Tag 的 GHCR 发布在记录发布目标时失败；现已改为 `release_tag`。

## 兼容性

- 任务 JSON、数据目录、导出包格式、Docker 卷名与端口不变。
- `compose.yaml` 默认镜像指向 `v2.6.1`；仍支持 `TGVD_DATA_DIR` 绑定宿主机目录。

## 验证

- 后端测试：`436 passed, 1 skipped`（`pytest -q tests`）。
- 前端测试：`189 pass, 0 fail`（`node --test "tests/js/*.test.mjs"`）。
- 桌面 / CLI：全平台构建通过（Windows x64/ARM64、Linux x64/ARM64、macOS x64/arm64）。
- Docker：`linux/amd64` 与 `linux/arm64` 构建验证通过；GHCR `v2.6.1` manifest 含两种架构。
- 在线 YAML 部署测试：拉取 main 的 `compose.yaml` 启动成功，`/healthz` 返回 `v2.6.1` 与 7 位构建 SHA。
