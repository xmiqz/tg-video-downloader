# 大屏结果区密度收紧（T61b 二次修复）

## 起因

上一版只在 `≥1280px` 放开 760px 窄带。实际终端窗口的 CSS 宽度经常落在
**1024–1279**（例如 1920 物理屏 125%–150% 缩放、或窗口非最大化），此时仍按
单列 760px 渲染，右侧一大片空白 —— 与用户截图一致（见 `before-1152x900.png`：
结果区 760px、右侧约 30% 空）。

## 改动（只动布局，不动 DOM / RPC / 移动端）

`web/css/views/new.css`：

- 媒体查询下界由 `1280px` 改为 `1024px`；
- 结果列表由固定列数改为自适应：
  `grid-template-columns: repeat(auto-fill, minmax(340px, 1fr))`；
- 保留：`.nw-wiz:has(.nw-list) { max-width: none }`、`.nw-row` 三段式模板、
  工具条 `nowrap` + 筛选框 `flex:1`（≤560px）+ 批量按钮右对齐、`max-height: 52vh`；
- `<640` 与 `640–1023` 断点一行未改。

`web/js/router.js`（1 处，防"改了看不出区别"）：

- 视图 CSS 由 `css/views/x.css` 改为 `css/views/x.css?v=<页面加载时间戳>`。
  升级后浏览器不会再复用旧 CSS；同一次页面加载内 URL 稳定，不影响缓存命中率。
